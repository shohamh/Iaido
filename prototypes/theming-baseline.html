01
Corner number

Swipe up on any letter for its number — no dedicated number row, keeping the minimal look.

02
Strip mirrors the sentence

The strip shows the last 2-3 words you actually typed, not generic suggestions — drag a word's reel and release to swap it, and the message updates live. This is the real mechanism: the IME can't touch the host app's text view directly, so correction happens here and edits the message via the keyboard's own text-editing API.

03
Comma / period, in place

No new punctuation row — they keep their normal slot and pick up swipe-to-space from there.
